# layered-self
The Layered Self

An interactive companion to doctoral research on online identity.

This small interactive piece accompanies the essay The Strange Case of Dr. LinkedIn and Mr. Instagram, which examines how workers compose and maintain a self-narrative across the several online profiles through which they are read. It renders a self as a set of translucent layers, one per profile: seen one at a time, each is partial, and can mislead; laid over one another, they compose a figure that no single profile shows.

Download one of the HTML files in the folder and open it in your browser (double-clicking on it should do it). 

Tick a profile to lay it over the face, or separate the layers to see each as its own plane.
